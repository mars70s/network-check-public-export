Legal and safety note 法務・安全上の注意

This function performs one normal HTTP HEAD request, with a safe GET fallback when needed, for one user-entered public URL. It does not perform port scanning, vulnerability scanning, exploit testing, unauthorized access, reputation scoring, address range scanning, or bulk crawling. Missing headers are displayed as information only and are not a vulnerability judgment.
この機能は、利用者が入力した1つの公開URLに対し、通常のHTTP HEADリクエストを行い、必要な場合のみ安全なGET fallbackを行います。ポートスキャン、脆弱性診断、exploit testing、不正アクセス、危険判定、アドレス範囲スキャン、大量クロールは行いません。未設定ヘッダーは情報として表示するだけで、脆弱性判定ではありません。
